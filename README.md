## 快速开始

**方式一：直接粘贴（推荐新手）**

1. 打开 [TradingView](https://www.tradingview.com)
2. 打开任意 A 股（如 `SSE:510050`）或台股（如 `TWSE:2330`）图表
3. 点击底部 **Pine 编辑器** 标签
4. 粘贴 `chanlun_core.pine` 全部代码
5. 点击 **添加到图表**

**方式二：Git Clone（推荐开发者）**

```bash
git clone https://github.com/Ye-Yu-Mo/chanlun_pine.git
```
然后将 `chanlun_core.pine` 内容粘贴到 TradingView Pine 编辑器。

首次加载后，在底部 **Pine 日志** 面板可以看到统计信息：

```

分型: 2,590 → 笔: 1,643 → 中枢: 270
趋势背驰: 630 → 盘整背驰: 238
买点: B1=21 B2=18 B3=1 | 卖点: S1=8 S2=6 S3=1
✓ 分型交替检查通过（顶底严格交替）
✓ 笔方向交替检查通过
✓ 中枢合法性检查通过（笔数≥3, ZG>ZD）
```

## 图表元素说明

| 元素 | 外观 | 含义 |
|------|------|------|
| 分型标记 | 红色 ▼ "顶" / 绿色 ▲ "底" | 顶分型和底分型，缠论的基本几何单元 |
| 笔连线 | 红色实线（向上笔）/ 绿色实线（向下笔） | 相邻交替分型的连线，趋势基本单元 |
| 中枢框 | 蓝色/紫色虚线矩形 | 至少三笔价格重叠形成的震荡区间 |
| 中枢 GG/DD | 浅色虚线 | 中枢内部实际价格波动的高低极值 |
| 趋势背驰 | "顶背"(红) / "底背"(绿) | 同向趋势笔价格更极端但 MACD 力度衰竭 |
| 买卖点 | B1/B2/B3(绿) / S1/S2/S3(红) | 三类买卖信号，颜色越深强度越高 |
| 预判面板 | 右上角表格 | 实时触发价和距离，仅盘中显示 |

## 参数说明

### 笔设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 笔最少K线数 | 3 | 每笔至少跨越的原始K线数。A股日线建议 3，ETF 可保持 3 |
| 笔最小价格变化 | 0% | 过滤价格变化不足的噪音笔。建议 A 股个股 0.5-1.0%，ETF 0.2-0.5% |
| 显示笔信息标签 | 关闭 | 开启后在每笔终点显示 K 线数和价格变化 |

### 中枢设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 中枢最少笔数 | 3 | 禅师原文标准 = 3。增大可减少中枢数量 |
| 中枢最小宽度 | 0% | 过滤 ZG-ZD 过窄的伪中枢。建议 0.1-0.3% |
| 显示中枢级别 | 关闭 | 开启后在中枢框标注笔数 |

### MACD / 背驰
| 参数 | 默认值 | 说明 |
|------|--------|------|
| MACD 快线/慢线/信号线 | 12/26/9 | 标准 MACD 参数 |
| 背驰面积比阈值 | 0.8 | 当前笔面积/参考笔面积 < 此值 = 背驰。越小越严格 |
| 显示背驰信号 | 开启 | 趋势背驰的"顶背"/"底背"标记 |
| 显示盘整背驰 | 关闭 | 盘整背驰信号较多，默认关闭 |

### 买卖点设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 显示买点/卖点 | 开启 | B1/B2/B3 和 S1/S2/S3 的开关 |
| 同类型信号最小间距 | 10 根K线 | 两个同类型买卖点之间的最短距离 |
| 显示第二类买卖点 | 开启 | B2/S2 独立开关 |
| 显示第三类买卖点 | 开启 | B3/S3 独立开关 |

### 预判设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 显示预判面板 | 开启 | 右上角实时预判表格 |
| 告警价格偏差 | 0.5% | 当前价与触发价偏差 < 此值时触发 Alert |

## 信号解读

### 第一类买卖点 (B1/S1) — 趋势反转
- **B1（一买）**：下跌趋势末端，底背驰确认后触发。最强买入信号
- **S1（一卖）**：上涨趋势末端，顶背驰确认后触发。最强卖出信号
- **注意**：趋势背驰是"必要不充分条件"——B1 后可能还有新低（背了又背），需结合仓位管理

### 第二类买卖点 (B2/S2) — 二次确认
- **B2（二买）**：B1 后反弹再回踩，不创新低 → 二次买入机会
- **S2（二卖）**：S1 后回落再反弹，不创新高 → 二次卖出机会
- **安全边际**：B2 比 B1 风险更低（趋势已确认反转），但价格也更高

### 第三类买卖点 (B3/S3) — 趋势延续
- **B3（三买）**：中枢上方，离开段向上后回调不破 ZG → 趋势延续买点
- **S3（三卖）**：中枢下方，离开段向下后反弹不破 ZD → 趋势延续卖点
- **用法**：确认中枢后趋势方向不变，在中枢边界入场

### 信号强度排序
```
B1 > B2 > B3（买点可靠性递减）
S1 > S2 > S3（卖点可靠性递减）
```

## 实时预判面板

在盘中（K线未收盘时），右上角显示预判表格：

```
┌──────┬──────────┬──────────┬────────┬──────────────────┐
│ 信号 │  触发价  │  当前价  │ 距离%  │     触发条件     │
├──────┼──────────┼──────────┼────────┼──────────────────┤
│  B1  │  3,050   │  3,120   │ +2.3%  │ 新低+底背驰→B1   │
│  B3  │  3,100   │  3,120   │ -0.6%  │ 回调不破ZG→B3    │
│  S1  │  3,450   │  3,120   │ -9.6%  │ 新高+顶背驰→S1   │
└──────┴──────────┴──────────┴────────┴──────────────────┘
```

- **正距离**（绿色）：当前价高于触发价 → 价格需要下跌才能触发
- **负距离**（红色）：当前价低于触发价 → 价格需要上涨才能触发
- **⚠️ 重要**：预判价仅供参考！K线未收盘前的包含处理、分型识别可能改变实际触发价

### 告警设置
1. 点击 TradingView 右侧 **警报** 按钮
2. 条件选择 **缠论核心**
3. 当价格接近触发价时会收到通知 → 可以提前挂限价单

## 不同标的参数建议

| 标的类型 | 笔最小价格变化 | 背驰面积比阈值 | 原因 |
|----------|---------------|---------------|------|
| A 股个股 | 0.5-1.0% | 0.75 | 波动较大，需过滤噪音 |
| A 股 ETF | 0.2-0.5% | 0.80 | 波动偏小，参数放宽 |
| 台股个股 | 0.3-0.7% | 0.78 | 特性介于 A 股个股和 ETF 之间 |
| 台股 ETF | 0.1-0.3% | 0.85 | 波动最小，参数最宽松 |

## 常见问题

**Q: 为什么图上笔这么多/这么密？**
A: 3K 宽松版 + 未启用价格过滤。建议调高"笔最小价格变化"参数。

**Q: 为什么某个明显的转折点没有买卖点信号？**
A: 可能原因：① 背驰条件未满足（面积比不够低）② 信号被间距过滤掉了（减小"最小间距"）③ 中枢未形成，B3/S3 不触发。

**Q: 趋势背驰和盘整背驰有什么区别？**
A: 趋势背驰 = 跨中枢的趋势笔比较（反转信号）。盘整背驰 = 中枢内部同向笔比较（震荡衰竭信号）。默认只显示趋势背驰。

**Q: 预判面板在历史回放时不显示？**
A: 正常行为。预判只在盘中实时 K 线（`barstate.isrealtime`）时显示。历史数据不需要预判——信号已经确认了。

**Q: 如何做多级别联立分析？**
A: 在 TradingView 上开多个图表窗格（日线 + 30分钟 + 5分钟），每个窗格加载同一个脚本。开启"同步品种"功能，对比各周期的中枢位置和买卖点共振。

**Q: 加载太慢？**
A: ① 减少图表 K 线数量（设置 → 图表属性 → 最大 K 线数）② 关闭不需要的显示项（如盘整背驰、笔信息标签、调试模式）。
