> **基于缠中说禅理论的 TradingView 全功能技术指标。** 包含处理 → 分型 → 笔 → 中枢 → 背驰 → 三类买卖点 → 实时预判，一条完整的 M0-M6 管线。附带止损参考、信号质量评分、MA 趋势过滤、非交易时段面板持久化。

## 快速开始

**方式一：直接粘贴（推荐新手）**

1. 打开 [TradingView](https://www.tradingview.com)
2. 打开任意 A 股（如 `SSE:510050`）或台股（如 `TWSE:2330`）图表
3. 点击底部 **Pine 编辑器** 标签
4. 粘贴 `chanlun_core.pine` 全部代码
5. 点击 **添加到图表**

**方式二：Git Clone（推荐开发者）**

```bash
git clone https://github.com/Ye-Yu-Mo/chanlun_pine.git
```
然后将 `chanlun_core.pine` 内容粘贴到 TradingView Pine 编辑器。

首次加载后，在底部 **Pine 日志** 面板可以看到全链路统计：

```

分型: 1,920 → 笔: 1,291 → 中枢: 205
趋势背驰: 217 → 盘整背驰: 163
买点: B1=30 B2=21 B3=1 | 卖点: S1=13 S2=12 S3=1
连续同向分型: N 对（同向选择由 buildBi 处理）
✓ 笔方向交替检查通过
✓ 笔时间顺序检查通过（startOrigIndex < endOrigIndex）
✓ 中枢合法性检查通过（笔数≥3, ZG>ZD）
```

## 图表元素说明

| 元素 | 外观 | 含义 |
|------|------|------|
| 分型标记 | 红色 ▼ "顶" / 绿色 ▲ "底" | 顶分型和底分型，缠论的基本几何单元。v1.2.0 起显示**原始分型**（含被笔算法跳过的同向相邻分型），图上可能出现"顶顶"并列 |
| 笔连线 | 红色实线（向上笔）/ 绿色实线（向下笔） | 相邻交替分型的连线，趋势基本单元 |
| 中枢框 | 蓝色/紫色虚线矩形 | 至少三笔价格重叠形成的震荡区间 |
| 中枢 GG/DD | 浅色虚线 | 中枢内部实际价格波动的高低极值 |
| 趋势背驰 | "顶背"(红) / "底背"(绿) | 跨中枢的同向趋势笔价格更极端但 MACD 力度衰竭 |
| 盘整背驰 | "盘顶背"(蓝) / "盘底背"(橙) | 中枢内部同向笔力度衰竭（默认关闭） |
| 买卖点 | B1/B2/B3(绿) / S1/S2/S3(红) | 三类买卖信号，颜色越深强度越高 |
| ★ 质量评分 | ★85 绿 / ★50 黄 / ★20 灰 | 信号质量 0-100，含背驰强度+中枢成熟度+趋势一致性 |
| 止损价 | 信号标签末尾 "止损 X.XX" | 参考止损位，B2/B3/S2/S3 对应关键支撑/压力 |
| MA 过滤 | 灰色标签 + [MA过滤] | 逆势信号被 MA 趋势过滤时（默认关闭） |
| 预判面板 | 右上角 7 列表格 | 实时触发价 + 止损位 + 距止损% + 状态标记 |

## 参数说明

### 笔设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 笔最少K线数 | 5 | 每笔至少跨越的**处理后**K线数（无包含关系），含两端分型K线。禅师原文要求≥5。A股日线建议 5，ETF/分钟图可放宽 3-4 |
| 笔最小价格变化 | 0% | 过滤价格变化不足的噪音笔。建议 A 股个股 0.5-1.0%，ETF 0.2-0.5% |
| 显示笔信息标签 | 关闭 | 开启后在每笔终点显示 K 线数和价格变化 |

### 中枢设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 中枢最少笔数 | 3 | 禅师原文标准 = 3。增大可减少中枢数量 |
| 中枢最小宽度 | 0% | 过滤 ZG-ZD 过窄的伪中枢。建议 0.1-0.3% |
| 显示中枢级别 | 关闭 | 开启后在中枢框标注笔数 |

### MACD / 背驰
| 参数 | 默认值 | 说明 |
|------|--------|------|
| MACD 快线/慢线/信号线 | 12/26/9 | 标准 MACD 参数 |
| 背驰面积比阈值 | 0.8 | 当前笔面积/参考笔面积 < 此值 = 背驰。越小越严格 |
| 显示背驰信号 | 开启 | 趋势背驰的"顶背"/"底背"标记 |
| 显示盘整背驰 | 关闭 | 盘整背驰信号较多，默认关闭 |

### 买卖点设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 显示买点/卖点 | 开启 | B1/B2/B3 和 S1/S2/S3 的开关 |
| 同类型信号最小间距 | 10 根K线 | 两个同类型买卖点之间的最短距离 |
| 显示第二类买卖点 | 开启 | B2/S2 独立开关 |
| 显示第三类买卖点 | 开启 | B3/S3 独立开关 |

### 止损设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 显示止损信息 | 开启 | 在信号标签和预判面板中显示参考止损位 |
| ATR 周期 | 14 | 动态止损距离的 ATR 周期 |
| ATR 倍数 | 1.5 | 止损距离 = max(ATR×倍数, 价格×2%) |

### 信号过滤设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 显示信号质量评分 | 开启 | 信号标签末尾追加 ★ 质量评分（0-100） |
| 最低信号质量 | 0 | 只显示评分 ≥ 此值的信号。0=不过滤 |
| 启用 MA 趋势过滤 | 关闭 | 价格在 MA 上方只收买点、下方只收卖点 |
| MA 趋势周期 | 60 | 均线周期，启用趋势过滤时生效 |

### 预判设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 显示预判面板 | 开启 | 右上角实时预判表格，非交易时段显示缓存数据 |
| 告警价格偏差 | 0.5% | 当前价与触发价偏差 < 此值时触发 Alert |

## 信号解读

### 第一类买卖点 (B1/S1) — 趋势反转
- **B1（一买）**：下跌趋势末端，离开段跌破进入段前低 + MACD 底背驰确认。最强买入信号
- **S1（一卖）**：上涨趋势末端，离开段突破进入段前高 + MACD 顶背驰确认。最强卖出信号
- **注意**：趋势背驰是"必要不充分条件"——B1 后可能还有新低（背了又背），需结合仓位管理

### 第二类买卖点 (B2/S2) — 二次确认
- **B2（二买）**：B1 后反弹再回踩，不创新低 → 二次买入机会
- **S2（二卖）**：S1 后回落再反弹，不创新高 → 二次卖出机会
- **安全边际**：B2 比 B1 风险更低（趋势已确认反转），但价格也更高
- **止损参考**：B1/S1 价格本身即为关键支撑/压力，跌破/突破即失效

### 第三类买卖点 (B3/S3) — 趋势延续
- **B3（三买）**：中枢上方，离开段向上后回调不破 ZG → 趋势延续买点
- **S3（三卖）**：中枢下方，离开段向下后反弹不破 ZD → 趋势延续卖点
- **止损参考**：ZD（B3 止损）/ ZG（S3 止损），中枢边界是关键防线

### 信号质量评分 (★)
每个信号附带 0-100 质量评分，权重分配：
- **背驰强度 45%**：MACD 面积比越小，背驰越可靠（仅 B1/S1）
- **中枢成熟度 25%**：中枢笔数越多，盘整越充分
- **趋势一致性 30%**：顺势信号（上升趋势中的买点）高分，逆势低分

显示规则：★85+ 绿色、★50-84 黄色、★<50 灰色。

### 信号强度排序
```
B1 > B2 > B3（买点可靠性递减）
S1 > S2 > S3（卖点可靠性递减）
```

## 实时预判面板

盘中显示实时的 7 列预判表格：

```
┌──────┬──────────┬──────────┬────────┬──────────┬──────────┬──────────────────────┐
│ 信号 │  触发价  │  当前价  │ 距离%  │  止损位  │ 距止损%  │       触发条件       │
├──────┼──────────┼──────────┼────────┼──────────┼──────────┼──────────────────────┤
│  B1  │  3,050   │  3,120   │ +2.3%  │  3,015   │  +3.5%   │ ⏳ 等待中 跌破前低... │
│  B3  │  3,100   │  3,120   │ -0.6%  │  3,080   │  +1.3%   │ ⏳ 等待中 回调不破ZG..  │
│  S1  │  3,450   │  3,120   │ -9.6%  │  3,490   │ -10.5%   │ ⏳ 等待中 突破前高... │
└──────┴──────────┴──────────┴────────┴──────────┴──────────┴──────────────────────┘
```

**列说明**：
- **距离%**：绿 = 价格在上方、红 = 价格在下方
- **止损位**：信号触发后的参考止损价（可关闭）
- **距止损%**：当前价到止损价的距离（可关闭）
- **触发条件**：状态标记 + 触发逻辑描述

**预判状态**：
- ⏳ **等待中**：结构条件满足，等待价格到达触发价
- ⏳ **观察背驰**：价格已破触发价，等待 MACD 背驰确认
- ⏳ **形成中**：离开段尚未完成，但价格已在突破中枢边界
- ✅ **已触发**：对应信号已生成

**非交易时段**：面板保留最后一次实时数据。表头显示 `[非交易时段]`，当前价标注 `(收盘)`，距离% 显示 `--`。

### 告警设置
1. 点击 TradingView 右侧 **警报** 按钮
2. 条件选择 **缠论核心**
3. 当价格接近触发价（偏差 < 告警阈值）时收到通知
4. 已触发的预判不再重复告警

## 常见问题

**Q: 为什么图上笔这么多/这么密？**
A: 默认未启用价格过滤。建议调高"笔最小价格变化"参数（个股 0.5-1.0%，ETF 0.2-0.5%）。

**Q: 为什么某个明显的转折点没有买卖点信号？**
A: 可能原因：① 背驰条件未满足（面积比不够低）② 信号被间距过滤掉了（减小"最小间距"）③ 中枢未形成，B3/S3 不触发 ④ 被"最低信号质量"阈值过滤了。

**Q: 趋势背驰和盘整背驰有什么区别？**
A: 趋势背驰 = 跨中枢的趋势笔比较（反转信号）。盘整背驰 = 中枢内部同向笔比较（震荡衰竭信号）。默认只显示趋势背驰。

**Q: 预判面板在历史回放时不显示？**
A: 正常行为。预判面板在实时 K 线和图表首次加载完成时显示。历史回放中不需要预判——信号已经确认了。

**Q: 非交易时段打开图表，预判面板空白？**
A: 图表首次加载完成后会自动计算并缓存预判数据。如果仍然空白，检查"显示预判面板"是否开启。缓存数据在脚本重载时丢失（TradingView 限制），重新加载图表即可。

**Q: ★ 质量评分为什么有的信号没有？**
A: 检查"显示信号质量评分"是否开启。即使关闭评分显示，信号检测和过滤逻辑不变。

**Q: 如何做多级别联立分析？**
A: 在 TradingView 上开多个图表窗格（日线 + 30分钟 + 5分钟），每个窗格加载同一个脚本。开启"同步品种"功能，对比各周期的中枢位置和买卖点共振。TradingView 的 Pine Script 不支持跨周期 UDT 传递，这是平台硬限制。

**Q: 加载太慢？**
A: ① 减少图表 K 线数量（设置 → 图表属性 → 最大 K 线数）② 关闭不需要的显示项（如盘整背驰、笔信息标签、调试模式）③ 关闭信号质量评分和止损显示。

### v1.2.0 更新详情

| 模块 | 内容 |
|------|------|
| **M1 笔构建重写** | 删除 `filterAlternatingFractals()` 预过滤，同向分型处理内化到 `buildBi()` 两阶段扫描（阶段1 定起点 + 阶段2 定终点），消除"同向取极端"造成的分型信息丢失；孤立分型 `continue` 跳过而非终止；最佳终点按价格变化评分 |
| **M2 间距对齐缠论** | 笔间距从"原始K线数"改为"合并后K线数"（无包含关系），对齐禅师原文"至少5根无包含K线"定义 |

| **M4 诊断增强** | 新增 `[buildBi]` 两阶段扫描诊断日志（由"显示 buildBi 诊断日志"开关控制）；日志段新增"笔时间顺序检查"，"分型交替检查"改为"连续同向分型统计" |

**⚠️ 行为变化**：分型三角标记和"顶/底"文字标签改为显示**原始分型**（含同向相邻分型），图表上可能出现"顶顶"并列——这是预期行为，笔的起止点仍由两阶段算法精度控制。
